## Decision quality (Duke, Kahneman)
- **Thinking in bets** — decisions are bets on futures; ask "wanna bet?" to surface real confidence. → thinking-in-bets
- **Resulting** — judging a decision by its outcome; the cardinal sin. → thinking-in-bets
- **Outside view / base rates / reference-class forecasting** — start from the class statistics, then adjust. → thinking-fast-and-slow (planning fallacy chs.)
- **System 1 / System 2; substitution; WYSIATI** — fast intuition answers an easier question with what's visible. → thinking-fast-and-slow
- **Prospect theory, loss aversion, anchoring, framing** — value is reference-dependent; losses loom ~2x. → thinking-fast-and-slow
- **Pre-mortem (Klein, via Kahneman)** — assume failure, narrate why; legitimizes dissent. → thinking-fast-and-slow
- **One-way vs two-way doors** — irreversibility budgets deliberation time.
