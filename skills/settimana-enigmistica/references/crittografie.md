# Crittografie — the double-reading discipline

An ESPOSTO (a short exposed text, often 2–4 letters or a word) plus a letter pattern (e.g. "1 5: 2 4"). The solution is a phrase that BOTH (a) describes/resolves the esposto through the declared mechanism and (b) re-reads, re-split, as a common Italian phrase matching the pattern.

Types (the header declares which):
- **Crittografia mnemonica** — the solution phrase is a well-known expression that wittily DESCRIBES the esposto. Pure lateral thinking: list idioms/titles/sayings matching the pattern, test each against the esposto.
- **Crittografia sinonimica** — replace (part of) the esposto with a synonym, read on.
- **Crittografia a frase** — the first reading is itself a sentence about the esposto's letters ("C in ASA" style positional statements: letter X in/near/before Y), which respelled gives the final phrase.
- **Crittografia perifrastica** — a periphrasis of the esposto supplies the letters.

Method: (1) write the pattern as slots; (2) generate first-readings by the declared mechanism, treating letters as OBJECTS that can be described positionally (D dentro ORO → D-OR-O...); (3) re-split into the final phrase; (4) verify both readings hold completely — a crittografia with one loose letter is unsolved.
