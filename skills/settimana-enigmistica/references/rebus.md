# Rebus — reading conventions

The rebus reads GRAFEMI (letters printed in the vignette) and FIGURE (depicted things, named in Italian) strictly in visual order, concatenated, then re-split at the cesura to form the solution phrase.

1. **Inventory pass:** list every printed letter and every depicted object left-to-right, top-to-bottom. Name objects with the puzzle-standard word (short, common: RE not SOVRANO, ORO not METALLO) — if a name doesn't fit the arithmetic, try synonyms of the SAME picture before re-reading the picture.
2. **The arithmetic:** the clue gives the solution pattern, e.g. "FRASE: 4 7". Total letters of grafemi+figure MUST equal the pattern total. Mismatch = wrong object name or missed grapheme, always.
3. **The cesura:** the continuous letter string re-splits at different points than the source words — that re-splitting IS the puzzle's beauty. Work both ends: what 4-letter words could start the phrase; what does the string force?
4. **Sub-types:** rebus stereoscopico (two readings), a domanda e risposta, anagrammato (letters also permute — the clue says so). The clue always declares the variant.
5. **Verify:** final phrase must (a) match the letter pattern exactly, (b) be natural Italian, (c) consume every grapheme and figure exactly once, in order.
