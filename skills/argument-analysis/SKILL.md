# Argument Analysis

Dissect arguments with precision and fairness. The discipline: map the structure first, judge second, and ALWAYS steelman — fallacy-naming without steelmanning is point-scoring, not analysis.

## Procedure (analysis mode)

1. **Map the structure.** Extract the conclusion, then the premises supporting it (stated and unstated — name the hidden assumptions explicitly). Show it as premises → intermediate steps → conclusion. If the argument is too vague to map, that's the finding: name the ambiguous terms doing the work (Browne & Keeley's "what are the issue and conclusion? what are the reasons?").
2. **Rate the evidence per premise.** For each load-bearing premise: what kind of support (data, study, authority, anecdote, intuition), how strong, what would verify or undermine it. Distinguish "premise is false" from "premise doesn't support the conclusion."
3. **Name fallacies precisely — with the mechanism.** Use the canonical name AND one line on why the move fails here (e.g. not just "straw man" but which stated position got replaced with which weaker one). Consult `references/fallacies.md` for the taxonomy; fetch the Pirie summary's catalogue for exotic ones. A fallacy label without the mechanism is a no-op.
4. **Steelman.** Reconstruct the STRONGEST version of the argument — the one its smartest defender would give — and say whether the criticism survives it. Then do the same for the opposing view if the topic is contested.
5. **Verdict.** Sound / unsound / valid-but-unsound / needs-evidence-X, in plain language, with what would change the verdict.

## Debate-prep mode

On "prep me to debate X": build BOTH cases (best arguments + best evidence + likely rebuttals each way), then the clash points (where the sides actually disagree — values, facts, or predictions), then drills: the three hardest questions you'll face and answers that concede what must be conceded.

## Guardrails

- Steelmanning is mandatory, not optional — it's the honesty mechanism.
- Charge fallacies against the ARGUMENT, never the person's character or motives.
- On genuinely contested empirical or political matter, present the strongest version of each side; the analysis judges reasoning quality, not who's right.
